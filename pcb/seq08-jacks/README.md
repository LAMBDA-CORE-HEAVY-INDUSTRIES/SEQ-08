# SEQ-08 jack board

This passive panel PCB holds nineteen PJ398SM jacks:

- J1-J8: CV outputs
- J9-J16: gate outputs
- J17: clock input
- J18: clock output
- J19: reset input
- J24-J25: keyed IDC connections to the main board

The clock and reset normal contacts connect to ground. Other normal contacts remain unconnected.

The provisional board is 160 x 100 mm with four 3.2 mm M3 mounting holes. Confirm the enclosure geometry before routing or ordering it.
